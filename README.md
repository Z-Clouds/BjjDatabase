# BJJ Database & Analytics Portfolio Project

## Overview
This repository is a comprehensive portfolio project focused on Brazilian Jiu-Jitsu (BJJ) competition data. It showcases end-to-end data engineering, analytics, and full-stack development skills, including scraping match data, cleaning and storing it, creating dashboards, and potentially serving it via an API and web interface.

## 🚀 Features

### 1. Web Scraping
- Pulls BJJ match data from BJJHeroes and SmoothComp
- Uses BeautifulSoup, requests, and modular utilities
- Auto-retries, logging, and pagination handling

### 2. Data Cleaning & Transformation
- Cleans, deduplicates, and normalizes fighter/match data
- Generates unique match IDs
- Formats for analysis, storage, or dashboards

### 3. Reporting & Dashboards
- Power BI visualizations (e.g., top athletes, win rates, submissions)
- Future: Streamlit/Dash apps for web-based analytics

### 4. Backend API (Planned)
- FastAPI endpoints to retrieve match and fighter stats
- Enables dynamic dashboarding or frontend integration

### 5. Frontend Web App (Planned)
- React or static site to explore fighters and event results interactively

## 💻 Technologies

## 🛠 Setup & Usage

### 1. Clone the Repo
```bash
git clone https://github.com/yourusername/BJJ_Database.git
cd BJJ_Database
```

### 2. Install Dependencies
With Poetry:
```bash
pip install poetry
poetry install
```

Or if using `requirements.txt`:
```bash
pip install -r requirements.txt
```

### 3. Environment Variables
Create a `.env` file or edit `config/settings.yaml` to include:
- API keys (if any)
- Output paths
- DB connection strings (if used)

### 4. Run Scrapers
```bash
python apps/scraper_smoothcomp/SC_Event_Scraper.py
# Or run notebooks from apps/scraper_bjjheroes/
```

### 5. Clean the Data
```bash
python apps/data_cleaning/clean_matches.py  # (or similar script)
```

### 6. Launch Power BI / Dashboard (manually open PBIX)

### 7. Serve API (if enabled)
```bash
uvicorn infra/backend/api.py:app --reload
```
